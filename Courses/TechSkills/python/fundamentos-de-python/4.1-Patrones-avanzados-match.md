
# Patrones avanzados en `match`

## ¿Qué es el *pattern matching*?

El `match` de Python no solo compara valores simples.
Puede **desestructurar y analizar estructuras completas de datos** como:

* listas
* tuplas
* diccionarios
* objetos

Esto se llama **pattern matching estructural**.

---

## Desestructuración de listas

Puedes hacer que el patrón coincida con la estructura de una lista.

```python
datos = [1, 2]

match datos:
    case [1, 2]:
        print("Lista exacta")
    case [1, x]:
        print(f"Empieza con 1 y termina con {x}")
    case _:
        print("Otra lista")
```

Salida:

```
Lista exacta
```

Aquí Python **desempaqueta automáticamente** la lista.

---

## Desestructuración con múltiples elementos

```python
datos = [10, 20, 30]

match datos:
    case [x, y, z]:
        print(f"x={x}, y={y}, z={z}")
```

Salida:

```
x=10, y=20, z=30
```

Esto es parecido al **desempaquetado de listas**, pero dentro del `match`.

---

## Usando `*` para capturar el resto

Puedes capturar múltiples elementos con `*`.

```python
numeros = [1, 2, 3, 4]

match numeros:
    case [1, *resto]:
        print(f"Empieza con 1 y el resto es {resto}")
```

Salida:

```
Empieza con 1 y el resto es [2, 3, 4]
```

---

## Patrones con diccionarios

También puedes hacer coincidencias con estructuras de diccionario.

```python
usuario = {"nombre": "Luis", "edad": 25}

match usuario:
    case {"nombre": nombre, "edad": edad}:
        print(f"{nombre} tiene {edad} años")
```

Salida:

```
Luis tiene 25 años
```

Python extrae automáticamente los valores.

---

## Coincidencias parciales en diccionarios

No necesitas definir todas las claves.

```python
usuario = {"nombre": "Luis", "edad": 25, "pais": "México"}

match usuario:
    case {"nombre": nombre}:
        print(f"Usuario: {nombre}")
```

Salida:

```
Usuario: Luis
```

---

## Usando condiciones adicionales (`if` guard)

Puedes agregar condiciones extra al patrón.

```python
edad = 20

match edad:
    case x if x >= 18:
        print("Mayor de edad")
    case _:
        print("Menor de edad")
```

Esto se llama **guard clause**.

---

## Comparación con `if`

Con `if` sería algo así:

```python
if isinstance(datos, list) and len(datos) == 2 and datos[0] == 1:
    print("Lista válida")
```

Con `match`:

```python
match datos:
    case [1, x]:
        print("Lista válida")
```

Mucho más **limpio y expresivo**.

---

## Cuándo usar `match`

Usa `match` cuando:

* Hay **muchos casos posibles**
* Trabajas con **estructuras de datos**
* Necesitas **desempaquetar valores**
* El código con `if/elif` se vuelve muy largo

Ejemplo típico:

```python
match comando:
    case "start":
        iniciar()
    case "stop":
        detener()
    case "restart":
        reiniciar()
```

---

## Cuándo **NO** usar `match`

No es buena idea usarlo cuando:

### Solo hay una condición simple

```python
if edad >= 18:
    print("Mayor de edad")
```

Usar `match` aquí sería innecesario.

---

### Cuando las condiciones son muy complejas

`match` funciona mejor con **estructuras**, no con lógica complicada.
