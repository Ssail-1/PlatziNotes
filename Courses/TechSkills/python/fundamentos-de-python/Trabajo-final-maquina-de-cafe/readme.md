# ☕ Máquina de Café — Práctica en Python

## 📖 Descripción

Programa de consola desarrollado como práctica del Curso de Fundamentos de Python.

Simula el funcionamiento básico de una máquina de café mediante un menú de opciones y un sistema de pedidos.

El objetivo principal fue aplicar los conocimientos adquiridos durante el curso y practicar la organización de un programa en varios módulos.

## 🛠️ Organización del código

| Archivo | Descripción |
|---|---|
| `main.py` | Punto de entrada del programa |
| `menu.py` | Funciones relacionadas con el menú |
| `pedidos.py` | Lógica de los pedidos |
| `historial.py` | Manejo del historial |
| `historial_pedidos.txt` | Archivo utilizado para registrar pedidos |

## 🚀 Cómo ejecutar

**Requisito:** tener Python 3 instalado.

1. Descarga o clona el repositorio.
2. Abre una terminal dentro de la carpeta `Trabajo-final-maquina-de-cafe`.
3. Ejecuta `python3 main.py`.
4. Sigue las indicaciones del programa.

## 📝 Sobre la práctica

Este proyecto fue desarrollado con fines educativos. Su propósito es demostrar la aplicación de fundamentos de Python mediante un programa funcional y organizado en módulos.
