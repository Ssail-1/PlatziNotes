
# Patrones útiles de `match` usados en proyectos reales

Estos patrones aparecen mucho en:

* **CLIs (command line tools)**
* **parsers**
* **frameworks**
* **manejo de estructuras de datos**
* **APIs**

## Captura de múltiples valores

Permite capturar valores directamente del patrón.

```python
comando = ("move", 10, 20)

match comando:
    case ("move", x, y):
        print(f"Mover a posición {x}, {y}")
```

Salida:

```bash
Mover a posición 10, 20
```

Esto es muy usado cuando se procesan **comandos o instrucciones**.

## Patrón de ignorar valores

Se usa `_` para ignorar partes del patrón.

```python
evento = ("click", 120, 300)

match evento:
    case ("click", _, _):
        print("Evento de clic detectado")
```

Aquí no importa la posición exacta.

## Patrón con tipos

Puedes combinar `match` con comprobaciones de tipo.

```python
valor = 42

match valor:
    case int():
        print("Es un entero")
    case str():
        print("Es una cadena")
```

Esto se usa mucho cuando procesas datos de **diferentes tipos**.

---

### Patrón con listas variables

Permite trabajar con listas de tamaño variable.

```python
datos = [1, 2, 3, 4, 5]

match datos:
    case [primero, *resto]:
        print(f"Primero: {primero}")
        print(f"Resto: {resto}")
```

Salida:

```bash
Primero: 1
Resto: [2, 3, 4, 5]
```

Muy útil para **procesar datos secuenciales**.

---

### Patrón con diccionarios estructurados

Se usa cuando recibes datos estructurados (por ejemplo JSON de una API).

```python
mensaje = {
    "tipo": "login",
    "usuario": "Luis"
}

match mensaje:
    case {"tipo": "login", "usuario": nombre}:
        print(f"Inicio de sesión de {nombre}")
```

Esto se usa mucho en:

* servidores
* bots
* procesamiento de APIs

---

## Caso real de uso

Un ejemplo típico en aplicaciones:

```python
accion = "delete"

match accion:
    case "create":
        print("Creando recurso")
    case "update":
        print("Actualizando recurso")
    case "delete":
        print("Eliminando recurso")
    case _:
        print("Acción desconocida")
```

Este patrón aparece mucho en:

* **APIs REST**
* **frameworks web**
* **herramientas CLI**

---

## Buenas prácticas al usar `match`

✔ Usarlo cuando hay **muchos casos posibles**
✔ Usarlo cuando trabajas con **estructuras de datos**
✔ Usarlo para **desempaquetar información**

Evitarlo cuando:

* solo hay una condición simple
* la lógica depende de muchas operaciones booleanas
* `if/elif` resulta más claro

---

## Idea clave

`match` no es solo un `switch`.

Es una herramienta de **pattern matching estructural**, lo que permite:

* analizar estructuras
* extraer datos
* escribir código más limpio
