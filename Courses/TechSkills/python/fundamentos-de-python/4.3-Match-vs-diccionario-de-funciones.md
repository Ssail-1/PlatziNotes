
# 🧠 `match` vs diccionario de funciones (patrón profesional)

En muchos programas, en lugar de usar múltiples `if/elif` o `match`, los desarrolladores utilizan un **diccionario que almacena funciones**.

Esto permite ejecutar acciones dinámicamente usando una clave.

---

## ⚙️ Ejemplo clásico con `match`

```python
comando = "start"

match comando:
    case "start":
        print("Iniciando sistema")
    case "stop":
        print("Deteniendo sistema")
    case "restart":
        print("Reiniciando sistema")
    case _:
        print("Comando desconocido")
```

Esto funciona bien cuando los casos son pocos.

Pero si el sistema crece, el código puede volverse muy largo.

---

## 🧩 Usando diccionario de funciones

Primero definimos funciones:

```python
def iniciar():
    print("Iniciando sistema")

def detener():
    print("Deteniendo sistema")

def reiniciar():
    print("Reiniciando sistema")
```

Luego creamos un diccionario que las relaciona con comandos:

```python
comandos = {
    "start": iniciar,
    "stop": detener,
    "restart": reiniciar
}
```

Ejecutamos así:

```python
comando = "start"

accion = comandos.get(comando)

if accion:
    accion()
else:
    print("Comando desconocido")
```

---

## 🚀 Ventajas

✔ Código más limpio  
✔ Escalable cuando hay muchos comandos  
✔ Permite registrar funciones dinámicamente  
✔ Muy usado en **CLIs, frameworks y APIs**  

---

## 📌 Comparación rápida

| Método                   | Ventaja                | Desventaja                  |
| ------------------------ | ---------------------- | --------------------------- |
| `if / elif`              | Simple                 | Se vuelve largo             |
| `match`                  | Claro con muchos casos | Menos flexible              |
| diccionario de funciones | Escalable y limpio     | Requiere entender funciones |

---

## 💡 Caso real de uso

Este patrón aparece mucho en:

* **CLI tools** (git, docker, etc.)
* **frameworks web**
* **routers de APIs**
* **sistemas de plugins**

Ejemplo conceptual:

```python
routes = {
    "/login": login_controller,
    "/logout": logout_controller,
    "/profile": profile_controller
}
```

El servidor ejecuta la función dependiendo de la ruta.

---

## 🧠 Idea clave

`match` sirve para **comparar patrones**.

Los **diccionarios de funciones** sirven para **despachar acciones**.

Por eso muchos desarrolladores usan ambos dependiendo del problema.
