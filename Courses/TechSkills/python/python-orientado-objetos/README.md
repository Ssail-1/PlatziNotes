## 📖 Descripción

Sistema de gestión de biblioteca desarrollado en Python como práctica para aplicar los principios de la **Programación Orientada a Objetos (POO)**.

El proyecto surgió como parte de mi formación y tiene como objetivo representar entidades de una biblioteca, gestionar operaciones relacionadas con libros y usuarios, y conservar la información mediante persistencia en archivos JSON.

Se trata de una aplicación de consola, desarrollada con fines educativos y de práctica.

## ⚙️ Funcionalidades

- Gestión de libros físicos y digitales mediante clases.
- Representación de distintos tipos de usuarios.
- Solicitud y devolución de libros.
- Validación de información y manejo de excepciones.
- Almacenamiento y recuperación de datos utilizando JSON.

## 🧠 Conceptos aplicados

- Clases, objetos y encapsulamiento.
- Herencia y polimorfismo.
- Métodos de instancia, de clase y estáticos.
- Propiedades mediante `@property`.
- Manejo de excepciones personalizadas.
- Modularización del código.
- Serialización y persistencia de información en archivos JSON.

## 📁 Estructura del proyecto

| Archivo | Responsabilidad |
|---|---|
| `main.py` | Punto de entrada e interacción con el usuario |
| `biblioteca.py` | Lógica relacionada con la biblioteca |
| `libros.py` | Definición y comportamiento de los libros |
| `usuarios.py` | Clases y comportamiento de los usuarios |
| `persistencia.py` | Guardado y recuperación de datos |
| `exceptions.py` | Excepciones personalizadas |
| `biblioteca.json` | Archivo de datos utilizado por la aplicación |
| `pyproject.toml` | Configuración del proyecto |

## 🚀 Cómo ejecutar el proyecto

**Requisitos:** tener instalado Python en una versión compatible con el proyecto. La versión utilizada durante el desarrollo puede consultarse en `.python-version`.

1. Clona o descarga el repositorio PlatziNotes.
2. Desde la raíz del repositorio, accede a `Courses/TechSkills/python/python-orientado-objetos`.
3. Ejecuta `python3 main.py`.
4. Interactúa con las opciones disponibles en la terminal.

El proyecto utiliza `biblioteca.json` para conservar información entre ejecuciones.
